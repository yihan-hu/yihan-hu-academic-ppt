# Academic Content → Guizang Layout Mapping

本文件只帮助**挑原 Guizang layout**。它不定义任何新 layout。

| Academic content shape | 优先 Guizang layout | 说明 |
|---|---|---|
| research question / hypothesis | S03 / S09 / S10 | statement 优先，不要做传统大学标题页 |
| single core finding | S03 / S09 / S12 | 用大结论建立 attention |
| cohort / registry / study design | S17 / S11 | system diagram 或 timeline |
| inclusion / exposure / follow-up timeline | S11 / S02 | 时间轴 |
| multiple analysis pipeline | S11 / S15 | 流程或矩阵 |
| model specification / covariate structure | S21 / S16 | spec sheet / brief grid |
| full publication/statistical figure | S22 | figure 是主角，默认 contain |
| figure + interpretation | S08 | 一侧 evidence，一侧 takeaway |
| published vs replication / treatment A vs B | S08 | 保持双方平权 |
| multiple figures / panels | S15 / S16 | 使用原多格骨架，不新造 evidence grid |
| scientific result table | S21 / S20 | 完整值保留；highlight 只引导 attention |
| definition / clinical mechanism | S14 / S17 | loop / system structure |
| three candidate explanations | S13 | 三等分逻辑 |
| four sensitivity analyses / four implications | S19 | 四等权 |
| why this matters / why now | S18 | 三论点 + evidence |
| closing / take-home | S10 / SWISS-CLOSING-ASCII | 保留 Guizang 收束节奏 |

## 选择原则

- 先看 content shape，再选 Sxx；不要先有“学术页模板”再硬套 Guizang。
- 如果一个 Sxx 装不下完整科学信息：优先拆为连续两页同 Sxx，或 overview → focus。
- 连续 Results 页允许重复 S22/S08/S21；这是对原版“多样性”规则的 Academic 明确例外。
- 任何新 layout 必须用户明确授权为 experimental；否则禁止。
